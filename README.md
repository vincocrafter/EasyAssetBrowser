# EasyAssetBrowser

**EasyAssetBrowser** is a web tool for managing, searching, and filtering Witcher 3 REDkit 3 assets. The tool is designed specifically for modders and worldbuilders who need to organize large amounts of meshes, entities, decals, and particles.

## Features

- Filter by category (Meshes, Entities, Decals, Particles)
- Filter by DLCs and Mini-DLCs
- Filter by predefined tags
- Search by name and file path
- Detailed view for each asset
